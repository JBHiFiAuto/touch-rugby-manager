Backup & Restore

Export — save a backup

Downloads a backup file of all your season data. Save it to your iPhone's Files app or iCloud.

Restore — load a backup

Select a previously exported backup file to restore your data. This will replace all current data.

Backup tips

• Export a backup after each game day.

• The file saves to your Downloads folder in the Files app.

• Updating the app on GitHub will never delete your data.

Reset — clear all data

Permanently deletes all players, rotations and season statistics. Export a backup first.
